# Структура репозитория и правила размещения

Верхний уровень зафиксирован планом проекта (этап Э4) и не меняется без согласования с ТЛ.

```
rkis-project/
├── django/        Бэкенд и веб-клиент
├── desktop/       Десктоп-клиент (Tkinter)
├── mobile/        Мобильный клиент (React Native, Expo)
├── design/        Макеты, ассеты, правила дизайна
├── docs/          Документация, протоколы, шаблоны
├── tests/         Чек-листы, тест-планы, баг-репорты
├── .github/       Шаблоны Pull Request и задач
├── .gitignore
└── README.md
```

## Что куда класть

| Что | Куда | Кто отвечает |
|---|---|---|
| Код сервера, модели, API, админка | `django/apps/<приложение>/` | БР |
| Настройки Django | `django/config/settings/` | БР |
| HTML-шаблоны | `django/templates/` (общие — в корне, остальные — по папкам приложений) | ФР |
| CSS, JS, картинки веба | `django/static/css`, `js`, `img` | ФР |
| Код десктопа | `desktop/` (`ui/`, `api/`, `utils/`) | ДР |
| Код мобайла | `mobile/src/` | МР |
| Макеты, исходные SVG, правила именования | `design/` | ДИ |
| Дизайн-система | `docs/design-system.md` | ДИ |
| Чек-листы, тест-планы, баг-репорты | `tests/` | QA |
| Шаблоны документов (баг-репорт, PR, задача) | `docs/templates/` | ТЛ, QA |
| Протоколы встреч | `docs/protocols/` | ТЛ |
| Архитектурные решения | `docs/architecture/` | БР, ТЛ |
| Скриншоты для отчётов и багов | `docs/screenshots/` | все |

## Правила

1. Каждый работает только в своей папке. Изменение чужой папки — через согласование с её владельцем и ревью.
2. Секреты (`.env`, ключи, пароли) не коммитятся. В репозитории лежит только `.env.example`.
3. Артефакты сборки и зависимости (`venv/`, `node_modules/`, `db.sqlite3`, `staticfiles/`, `media/`) не коммитятся: они в `.gitignore`.
4. Большие бинарные файлы в репозиторий не добавляются.
5. Имена файлов и папок: латиница, нижний регистр, слова через дефис или подчёркивание (Python-модули — через подчёркивание).
6. Ассеты именуются по правилам из `design/README.md`.
