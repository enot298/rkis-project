# Технические решения (журнал)

| № | Решение | Причина | Дата |
|---|---|---|---|
| 1 | Боевая СУБД — **PostgreSQL 14+**; в разработке — SQLite | Так зафиксировано в ТЗ и ER-схеме. Переключение только значением `DATABASE_URL`, код не меняется. | 24.10.2026 |
| 2 | **Django 5.2 LTS** | Поддержка Django 4.2 LTS закончилась в апреле 2026; 5.2 LTS поддерживается дольше. Требует Python 3.10+, в проекте — 3.11+. | 24.10.2026 |
| 3 | Настройки разделены: `config/settings/base.py`, `dev.py`, `prod.py` | Разные требования к безопасности. Значения берутся из переменных окружения (`python-dotenv`). | 24.10.2026 |
| 4 | Секреты только в `.env` (не коммитится), шаблон — `.env.example` | Требование задания; безопасность. | 24.10.2026 |
| 5 | Django REST Framework подключён сразу | Эндпоинты — на этапе Э7, но приложение уже в `INSTALLED_APPS`. | 24.10.2026 |
| 6 | Часовой пояс `Europe/Moscow`, язык `ru`, в БД хранится UTC (`USE_TZ=True`) | Соответствует API-контракту (даты в ISO 8601 UTC). | 24.10.2026 |
| 7 | Мобайл: **Expo** (managed workflow) | Камера, push и биометрия доступны через модули Expo; не нужны Android Studio и Xcode. Подробности — `mobile/README.md`. | 24.10.2026 |
| 8 | Десктоп: Tkinter, структура `ui/`, `api/`, `utils/` | Интерфейс отделён от обращения к серверу. Подробности — `desktop/README.md`. | 24.10.2026 |
| 9 | Шрифты системные, без внешних загрузок | Не зависит от интернета и ускоряет загрузку. | 24.10.2026 |
