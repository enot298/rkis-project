# Тестирование (QA)

Ответственный: Васильева С. (QA). Общий план тестирования — отдельный документ «План тестирования» (версия 1.0 от 03.10.2026).

## Структура

| Папка | Что лежит |
|---|---|
| `checklists/` | Чек-листы. Сейчас: `01-launch-checklist.md` — запуск проекта на чистой машине. |
| `test-plans/` | Тест-планы и описание окружения (`environment.md`). |
| `bug-reports/` | Баг-репорты по шаблону `docs/templates/bug-report.md`. Один файл на баг: `BUG-001-короткое-имя.md`. |

## Правила

1. Баг-репорт заводится по шаблону `docs/templates/bug-report.md`, формат один на все части проекта.
2. Идентификаторы сквозные: `BUG-001`, `BUG-002`, ...
3. К багу прикладываются скриншот или видео (файлы кладутся в `docs/screenshots/` и ссылаются из репорта).
4. Чек-лист прогоняется после каждого изменения инструкции запуска; результат фиксируется в самом файле (колонка «Результат»).
