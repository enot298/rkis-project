# Целевое окружение тестирования (черновик)

Начальная версия раздела «Окружение» будущего тест-плана. Значения взяты из ТЗ (разделы о совместимости). Составила: Васильева С. (QA).

## Серверная часть

| Параметр | Значение |
|---|---|
| Python | 3.11 или новее |
| Django | 5.2 LTS |
| СУБД в разработке | SQLite |
| СУБД боевая | PostgreSQL 14+ |

## Веб-клиент

| Параметр | Значение |
|---|---|
| Браузеры | Chrome 110+, Firefox 110+, Safari 16+ |
| Ширина экрана | от 360px (телефон) до 1280px и шире |

## Десктоп-клиент

| Параметр | Значение |
|---|---|
| ОС | Windows 10+, macOS 12+, Ubuntu 22.04 |
| Python | 3.11 или новее (Tkinter) |
| Разрешение экрана | от 1280×720 |
