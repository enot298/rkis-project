## A. Веб-часть (Django)

Команды выполняются по разделу «Как запустить: веб» из корневого `README.md`.

| № | Шаг | Ожидаемый результат | Прогон 1 | Прогон 2 | Примечание |
|---|---|---|---|---|---|
| A1 | `git clone <ссылка>` и переход в папку `django` | Папка склонирована, внутри есть `manage.py` | | | |
| A2 | Создать и активировать виртуальное окружение | В начале строки терминала появился `(venv)` | | | |
| A3 | `pip install -r requirements.txt` | Установка завершена без ошибок | | | |
| A4 | Скопировать `.env.example` в `.env` | Файл `.env` создан, в `git status` он не виден (игнорируется) | | | |
| A5 | `python manage.py migrate` | Миграции применены, создан файл `db.sqlite3` | | | |
| A6 | `python manage.py createsuperuser` | Суперпользователь создан | | | |

| A11 | Открыть инструменты разработчика браузера (F12), вкладка «Сеть»/«Консоль», обновить главную | Файлы `css/*.css`, `js/main.js`, `img/*.svg` загружаются со статусом 200, ошибок 404 нет | | | |
| A12 | Проверить внешний вид шапки и подвала | Видны логотип, пункты меню, имя пользователя, подвал | | | |

## B. Адаптивность (первое приближение)

Открыть `http://127.0.0.1:8000/` и `/orders/`, в инструментах разработчика включить режим телефона (Ctrl+Shift+M) и поставить ширину 360px.

| № | Шаг | Ожидаемый результат | Прогон 1 | Прогон 2 | Примечание |
|---|---|---|---|---|---|
| B1 | Ширина 360px: главная | Нет горизонтальной прокрутки страницы; карточки в одну колонку | | | |
| B2 | Ширина 360px: меню | Вместо меню — кнопка «бургер»; по нажатию меню раскрывается | | | |
| B3 | Ширина 360px: список заказов | Фильтры друг под другом; таблица прокручивается внутри своей рамки, страница не ломается | | | |
| B4 | Ширина 768px | Карточки в 2 колонки, вёрстка не разваливается | | | |
| B5 | Ширина 1280px | Меню в одну строку, карточки в 4 колонки, контент по центру | | | |
