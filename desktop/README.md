# Десктоп-клиент (Tkinter)

Клиент для бухгалтера. Сейчас — каркас: главное окно, меню, навигация между разделами-заглушками.

## Запуск

```
cd desktop
python -m venv venv
venv\Scripts\activate          # Windows;  macOS/Linux: source venv/bin/activate
pip install -r requirements.txt
python main.py
```

Требуется Python 3.11+. Tkinter входит в Python; на Ubuntu 22.04 его ставят командой `sudo apt install python3-tk`.
Целевые ОС: Windows 10+, macOS 12+, Ubuntu 22.04 (ТЗ).

Адрес сервера задаётся переменной окружения `APP_API_BASE_URL` (по умолчанию `http://127.0.0.1:8000/v1`).

## Структура и почему именно так

| Путь | Назначение |
|---|---|
| `main.py` | Точка входа, проверка версии Python. |
| `config.py` | Адрес сервера, таймаут, размер окна. Настройки отдельно от кода интерфейса. |
| `ui/` | Всё, что рисует окна. `main_window.py` — каркас окна, `screens/` — по модулю на раздел. |
| `api/` | Обращение к серверу. Интерфейс не знает про HTTP, поэтому API можно менять независимо. |
| `utils/` | Мелкие общие функции. |

## Проверка

Нужно проверить на целевой ОС: окно открывается, пункты меню и кнопки слева переключают разделы, внизу меняется строка состояния. Скриншот окна приложить в `docs/screenshots/`.
