# Мобильный клиент (React Native, Expo)

Клиент для кладовщика. Сейчас — каркас: три экрана-заглушки (список, детали, форма) со стековой навигацией.

## Требования

- Node.js 18+ (проверка: `node --version`).
- Приложение Expo Go на телефоне или эмулятор Android / симулятор iOS.
- Целевые платформы по ТЗ: Android 8.0+ (minSdk 26), iOS 15+. Заданы в `app.json`.

## Запуск

```
cd mobile
npm install
npx expo start
```

Затем отсканируйте QR-код в Expo Go или нажмите `a` (эмулятор Android) / `i` (симулятор iOS, только macOS).

### Если Expo Go пишет о несовместимой версии SDK

Версии пакетов в `package.json` соответствуют Expo SDK 52. Актуальный Expo Go работает с новой SDK, поэтому выполните:

```
npx expo install expo@latest
npx expo install --fix
```

После этого закоммитьте обновлённые `package.json` и `package-lock.json`, чтобы у всей команды были одинаковые версии.

## Почему Expo, а не bare workflow

В ТЗ для мобильного клиента нужны камера (штрих-коды), push-уведомления и биометрия. Для них есть готовые модули Expo (`expo-camera`, `expo-notifications`, `expo-local-authentication`), так что нативный код писать не придётся. Каркас запускается без Android Studio и Xcode, это удобно команде. Ограничение: push-уведомления на Android в Expo Go работают не полностью, их проверяют в development build (EAS). Это решается на этапе Э9–Э10; переход на bare workflow не требуется.

## Структура

| Путь | Назначение |
|---|---|
| `App.js` | Точка входа. |
| `src/navigation/` | Навигация между экранами. |
| `src/screens/` | Экраны: список, детали, форма заказа. |
| `src/components/` | Общие компоненты (кнопка, заголовок). |
| `src/theme/tokens.js` | Цвета, отступы, размеры — по дизайн-системе ДИ. |
| `src/config.js` | Адрес API (из `EXPO_PUBLIC_API_BASE_URL`, не из кода). |

## Проверка

Приложение открывается, кнопки на списке ведут на экраны «Заказ» и «Новый заказ», кнопка «Назад» возвращает к списку. Скриншоты с эмулятора/устройства положить в `docs/screenshots/`.
