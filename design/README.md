## Структура папок

| Путь | Что лежит |
|---|---|
| `design/assets/svg/` | Исходные SVG: логотип и иконки. Единственный источник правды. |
| `design/mockups/` | Макеты-каркасы: веб (`web-layout.svg`), десктоп (`desktop-frame.svg`), мобайл (`mobile-nav.svg`). |
| `docs/design-system.md` | Палитра, типографика, отступы, сетка. |

Тяжёлые исходники (`*.psd`, `*.ai`, `*.sketch`) в репозиторий не коммитятся (см. `.gitignore`): храните их в Figma или на общем диске.

## Правила именования ассетов

1. Только латиница в нижнем регистре, слова через дефис: `icon-orders.svg`.
2. Префикс по типу: `logo-*.svg` (логотипы), `icon-*.svg` (иконки), `img-*.*` (иллюстрации), `bg-*.*` (фоны).
3. После префикса — имя по смыслу, а не по виду: `icon-orders.svg`, а не `icon-clipboard.svg`.
4. Состояния и размеры — суффиксом: `icon-orders-active.svg`, `logo-mark-32.svg`.
5. Иконки: сетка 24x24, обводка 1.8px, скруглённые концы, цвет обводки `#1F2937`. Один стиль для всех.
6. SVG без лишнего кода: без метаданных редакторов, без встроенных растровых картинок.
7. Цвета в токенах: `color-primary`, `color-text-muted` (тот же вид, что в CSS-переменных `--color-primary`).

## Как передавать ассеты разработке

1. Положить файл в `design/assets/svg/` через Pull Request (ветка `feature/design-...`).
2. ФР копирует нужные файлы в `django/static/img/` **с тем же именем**.
3. Мобильная и десктопная части берут ассеты из `design/assets/svg/` по необходимости.
